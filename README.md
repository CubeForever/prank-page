# 🎃 灵魂性格解码 — 吓人网页(Prank Page)

> 一款基于 **HTML + Canvas + Web Audio API** 的纯前端整蛊小游戏。  
> 单文件部署、零依赖、移动端优先,适合朋友之间互相"惊吓"+ "逗趣"。

---

### 反差开场(2.0)

主惊吓前 **0.6 秒**先显示一段"看起来正常甚至温馨"的室内画面:
- 调暗暖客厅 + 模糊照片 + "一切正常 ✓" 字样
- 0.4s 起角落人偶逐渐浮现,灯光开始抖动
- 末期 0.2s 急速 zoom-in 1→6× 后闪白 → 直接切入恐怖画面

> 减弱动效:`drawNormal` 缩短至 0.25s,跳过浮尘/噪点/血液物理速度。

## 🚀 玩法流程

1. **首次进入** → 显示 **使用须知弹层**(只需同一会话确认一次)
2. **填写表单**(4 步):出生日期 → 性格关键词 → 性别姓名 → 手机号 + **强制勾选同意复选框**
3. **灵魂假分析**(4 秒):带进度环、装饰文案,营造"分析中"氛围
4. **🔊 主惊吓页面**(7 秒):
   - **0.6s 反差开场**(2.0):暖色客厅 + 模糊照片,角落人偶渐显 + 灯闪
   - 末期 0.2s **zoom-in 1→6×** + 闪白 → 切到恐怖脸
   - 前 2 秒:假安全期,画面逐步变得诡异
   - 第 3 秒:**主尖叫 + 屏幕冲击** (整体短促缩放 1.0→1.15→1.0)
   - 持续:Canvas 实时绘制照片级面部(多层皮肤光照/湿润高光/瞳孔呼吸/泪液湿层/带血牙列);血迹物理滴落/拖尾;环境浮尘 + 胶片噪点
5. **😈 二次惊吓**(2.5 秒后):画面切到巩膜纹理版巨眼特写 + 0→1.2→1.0 收缩冲击 + 飞溅血线 + 超短尖叫
6. **退出后** 表单自动复位,可再次体验

随时可点击右上角 **✕** 主动退出(前 3 秒为保护节奏禁用)。

## 🛡️ 安全与可访问性

| 防护项                       | 状态 | 说明                                                            |
| ---------------------------- | :--: | --------------------------------------------------------------- |
| 退出按钮(右上 ✕)            | ✅   | 恐怖页前 3 秒后即可一键中断                                       |
| 静音按钮(右上 🔊)            | ✅   | 一键关闭所有音效,不破坏画面节奏                                  |
| `prefers-reduced-motion`     | ✅   | 系统级"减少动效"开启时,自动降低抖动/闪烁幅度,跳过二次惊吓        |
| 闪烁安全阈值 (~3 Hz)         | ✅   | `flashOverlay` 间隔 ≥ 180 ms,降低光敏感癫痫风险                   |
| 隐私声明确认 + 强制复选       | ✅   | 首次进入须手动同意;提交须勾选复选框                               |
| **不发送任何数据**            | ✅   | 所有信息仅在浏览器内存,关闭即丢失                                |
| **无 `beforeunload` 阻止关闭** | ✅   | 用户随时可正常关闭/刷新,不再被骚扰                                |
| 页面隐藏暂停渲染             | ✅   | `document.visibilitychange` 暂停 Canvas 重绘、暂停音频           |
| 隐私弹层持久化              | ✅   | 用 `sessionStorage` 记住本会话确认,避免反复打扰                  |

- `js/canvas.js` — Canvas 绘制
- `js/main.js` — 状态机

## 🎨 技术栈概要

- **HTML5 Canvas 2D** — 主画面绘制(面部、血泪、闪烁、人偶、文字、巨眼)
- **Web Audio API** — 实时合成音效(心跳 / 吱呀 / 耳语 / 多层尖叫 / 低频轰鸣 / 倒放人声 / 二次冲击)
- **CSS Animation / Keyframes** — 闪烁血边框、扫描线、吐司
- **`navigator.vibrate`** — 移动端触觉反馈
- **`prefers-reduced-motion` 媒体查询** — 系统级可访问性尊重
- **`sessionStorage`** — 隐私同意一次一保持
- **`document.visibilityState`** — 后台标签自动暂停

## ⚙️ 调档(开发者可选)

所有硬编码参数集中在 `CONFIG` 对象(JS 顶部),可直接修改:

```js
const CONFIG = {
  HAIR_BACK_COUNT: 160,          // 后层头发根数
  HAIR_FRONT_COUNT: 60,          // 前层头发根数
  BLOOD_DROP_COUNT: 36,          // 血滴数
  SPOT_COUNT: 40,                // 面部腐烂斑点
  CRACK_COUNT: 25,               // 裂纹条数
  SCARE_DURATION_MS: 7000,       // 主惊吓时长(ms)
  SCARE_DURATION_REDUCED_MS: 5000, // 减弱动效时
  EXIT_BUTTON_DELAY_MS: 3000,    // 退出按钮延迟
  FLASH_INTERVAL_MIN_MS: 180,    // 闪烁最小间隔(光敏安全)
  // ... 更多参数见代码顶部
};
```

屏幕冲击时刻可在 `drawScaryFace` 内 `shockPoints` 数组调整:
```js
const shockPoints = [3, 3.5, 4.2, 5.5];
```
