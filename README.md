# 瞳渊 · 灵魂档案

> 一款移动端优先的纯前端整蛊网页：用最温馨的占卜小馆，把你引到深渊边缘，然后让一只「奶龙」突然回望你。

「瞳渊 · 灵魂档案」是一个三幕式反差惊吓（Jump Scare）体验。前半段以暖奶油色的玄学占卜界面让人放下戒备，加载仪式结束后瞬间坠入纯黑，一只圆胖可爱却动作诡异的奶龙在红光与扫描线中浮现 —— 越温柔，越吓人。

---

## 体验流程

| 幕次 | 页面 | 氛围 | 说明 |
| --- | --- | --- | --- |
| 一 · 诱饵 | `pages/form.html` | 暖奶油羊皮纸、灯笼光晕 | 选择生辰日期与十二时辰，点击「凝视深渊」 |
| 二 · 仪式 | `pages/analyzing.html` | 暖色调、旋转进度环 | 进度 0→100%（约 3.6 秒），低语文案层层递进，结束后自动跳转 |
| 三 · 惊吓 | `pages/scare.html` | 纯黑、血红、故障 | 奶龙抽象诡异动画循环，叠加开场闪烁、红色暗角、CRT 扫描线与故障文字 |

入口 `index.html` 会自动跳转到第一幕。

## 设计概念

- **品牌符号**：竖瞳之眼（Abyss Pupil）——「当你凝视深渊，深渊也在凝视你」。
- **极致反差**：诱饵幕使用暖奶油底色（`#f7efe1`）、可可棕文字与赤陶琥珀按钮，营造安全、温馨的占卜小馆；惊吓幕骤降为纯黑，血红色（`#e01010`）与骨白文字配合奶龙动画，形成色温与情绪的双重断崖。
- **诡异萌（Uncanny Cute）**：惊吓主体不是传统鬼脸，而是一只黄色圆胖、大眼僵笑的奶龙，靠不自然的抽搐、拉伸微笑与冷光制造「恐怖谷」式的荒诞惊吓。

所有品牌色、字号、间距与阴影都集中在 `colors_and_type.css` 的设计令牌（CSS 变量）中，方便统一换肤。

---

## 技术栈

- 原生 HTML + CSS，无构建步骤、无后端
- [Tailwind CSS](https://tailwindcss.com/)（浏览器 CDN）做原子样式
- [Lucide](https://lucide.dev/) 图标（CDN）
- CSS 变量设计令牌 + 原生 `@keyframes` 动画
- 单个 H.264 MP4 竖屏视频（9:16，约 1.7 MB，自动静音循环）
- 表单数据仅用 `sessionStorage` 暂存在本地，**不上传任何信息**

## 本地运行

直接双击 `index.html` 也能打开；推荐用任意静态服务器，以保证视频在各浏览器下正常加载：

```bash
# Python 3
python -m http.server 8000

# 或 Node.js
npx serve .
```

然后访问 <http://localhost:8000>。建议使用手机或浏览器的移动端模拟视口（390 × 844）体验。
